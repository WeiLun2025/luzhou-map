# 蘆洲平行世界：蘆北開發模擬器 (Luzhou Parallel World Simulator)

> **蘆洲在地居民自發整理・都市計畫生活衝擊情境模擬平台**  
> 一個基於地理資訊、都市計畫脈絡與生活衝擊的 2D 雙情境互動對比模擬器（What-If Simulator）。

---

## 📌 專案緣起與核心定位

本專案由新北市蘆洲區在地鄉親個人發起，針對在地高度關切的**「三重果菜市場搬遷蘆洲（銀河灣計畫）」**都市計畫案，以公民科學與都市規劃中常見的 **"What-If"（如果…會怎樣？）** 方式，將複雜的都市計畫與可能的生活衝擊進行可視化對比模擬，供全體居民與大眾理性想像、討論未來家園願景。

### 核心定位原則
- **回歸生活衝擊推演**：本站旨在模擬不同規劃決策對居民日常生活（如清晨重車交通、空氣異味、救護動線、綠地保留）可能產生的具體影響，不作為司法舉證或公文檢索系統。

## ✨ 核心特色與功能

- 🗺️ **免 API Key 暗黑底圖與多圖層切換**：
  - 預設採用 OpenStreetMap 正體中文圖資搭配高對比暗黑濾鏡，地名街道路名清晰無浮水印。
  - 右上角提供圖層切換控制：可自由切換「🌑 暗黑警示底圖」、「🗺️ 標準繁中街道」與「🛰️ 真實衛星空照圖」（直接透視蘆北現況農地與河堤）。
- 🎛️ **雙情境即時切換 (A/B Testing Slider)**：
  - **🔴 情境 A（若果菜市場進駐）**：模擬清晨批發車流湧入環堤大道、水肥站異味潛在擴散、急重症醫院包裹審查延宕之情境。
  - **🟢 情境 B（若維持原綠帶／兩案脫鉤）**：模擬親水綠地完整保留、生活路網維持單純、急重症醫院獨立優先動工之情境。
- 🎯 **一鍵回到初始視角**：
  - 右下角縮放按鈕上方的「準星」按鈕，點一下即平滑飛回蘆北初始位置與縮放等級，並自動關閉開啟中的彈窗，在手機上拖曳迷路時特別好用。
  - 初始視角集中定義於 `main.js` 的 `INITIAL_VIEW`（中心座標與縮放等級），修改該常數即可同步調整首次載入與重置位置。
  - 若系統設定為「減少動態效果」，會改為直接跳回、不播放飛行動畫。
- 🚦 **擬真動態交通路網 (Traffic Flow Polyline)**：
  - 具備**雙層感應線（Hitbox）**，手指或滑鼠隨意點擊周邊 20px 內皆能 100% 靈敏觸發。
  - 支援桌機 **Hover 浮動即時提示**（加粗發光高亮並顯示流速狀態）。
  - 成蘆橋、水湳街與環堤大道動態流動虛線方向經地理校正，逼真呈現車流動態。
- 📊 **即時生活衝擊儀表板 (HUD Impact Bar)**：
  - 底部浮動 HUD 儀表板，隨情境切換即時連動批發車流估計、綠地規劃、醫院時程與平均車速評估。
- 👴 **長輩與老花友善介面**：
  - 字體全面放大（標題 19px、內文 16px），採用生活白話大字卡，捨棄生硬艱澀公文詞彙。
  - 彈窗具備自動避讓機制，永遠不會被上方控制器遮擋。
- 📱 **行動裝置版面最佳化 (RWD)**：
  - 全頁高度改用 `dvh`（並保留 `vh` 備援），手機瀏覽器網址列收合時地圖與彈窗高度不再跑掉。
  - 頂部導覽列在 900px 以下可換行、600px 以下滿版（隱藏品牌標籤以節省空間），情境按鈕可自動折行。
  - 右上圖層切換鈕在小螢幕自動下移到導覽列下方；右下縮放／重置按鈕與圖資標示自動上移到 HUD 之上，不互相重疊。導覽列與 HUD 的實際高度由 `main.js` 量測後寫入 CSS 變數 `--navbar-h`、`--hud-h`。
  - 彈窗寬度會依螢幕縮窄（左右各留約 24px），內容過高時可在彈窗內捲動；彈窗自動平移時的安全邊距也依導覽列／HUD 實際位置動態計算。
  - 底部 HUD 在小螢幕可橫向滑動查看全部指標。
- 📸 **社群圖卡一鍵產生與複製 (html2canvas)**：
  - 每個 POI 點位或全景地圖均可一鍵截圖，合成自帶專案大標、情境標籤與生活分析的高畫質社群圖卡，方便鄉親轉傳至 Facebook 社團（如「我是蘆洲人」）與 LINE 親友群組。

```
│   └── docs/               # 官方會議紀錄、佐證文件備份
├── code_artifact.md        # 原始專案開發規劃規格書
└── README.md               # 專案說明與開發指引
```

## 🚀 快速啟動與本機測試

因為本專案使用 `fetch()` 讀取 `luzhou_pois.json`，請在本地 HTTP 伺服器環境下啟動：

### 方法 1：使用 Python 內建伺服器（推薦）
```bash
# 在專案根目錄下執行：
python3 -m http.server 8000
```
開啟瀏覽器前往：`http://localhost:8000`

### 方法 2：使用 VS Code Live Server
1. 在 VS Code 中安裝擴充功能 **Live Server**。
2. 在 `index.html` 按右鍵，選擇 **"Open with Live Server"**。

### 方法 3：使用 Node.js
```bash
npx serve .
```

### 📱 手機版面測試
- 桌機：F12 開啟開發者工具 ➔ 切換裝置模擬（Ctrl+Shift+M），分別測試 360×640、390×844、768×1024 與橫向。
- 實機：電腦與手機連同一個 Wi-Fi，以電腦區網 IP 開啟（例如 `http://192.168.x.x:8000`），並實際滑動網址列確認 `dvh` 行為。
- 重點檢查：導覽列是否遮住地圖、圖層鈕與縮放／重置鈕是否與導覽列、HUD 重疊、彈窗是否完整顯示、重置按鈕是否正確飛回起點。

## 🌐 部署方式

### 部署至 GitHub Pages
1. 將本專案 Push 至 GitHub 倉庫。
2. 前往 GitHub Repo ➔ **Settings** ➔ **Pages**。
3. 在 **Branch** 選擇 `main` / `master`，資料夾選擇 `/ (root)`，點擊 **Save** 即可免費上線。

### 部署至 Vercel
1. 安裝 Vercel CLI：`npm i -g vercel`
2. 在專案根目錄執行 `vercel`，按預設步驟完成發佈。
